# Химична лаборатория

Интерактивно Python уеб приложение за симулиране на химични реакции в училищна лаборатория.

## Стартиране

```powershell
python app.py
```

След това отвори:

```text
http://127.0.0.1:8000
```

## Какво включва

- избор на химична реакция;
- добавяне на изходни вещества за собствен опит;
- изходни вещества и продукти в епруветки;
- анимирано смесване в реакционен съд;
- наблюдение, обяснение, уравнение и бележка за безопасност;
- мини въпрос за проверка на разбирането.
